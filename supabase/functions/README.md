# Supabase Edge Functions

This directory holds TypeScript Edge Functions deployed to Deno runtime in Supabase.

## Future Scope (PS-089)
* AI demand forecasting calculation endpoints.
* Split payment disbursement webhooks / simulation.
* Automated notification triggers.

## Development
To create a function:
```bash
npx supabase functions new <function_name>
```
To serve locally:
```bash
npx supabase functions serve
```
