# Feature Modules

This directory contains domain-driven feature modules for PS-089:
- `auth/`: Authentication, OTP login, registration, and role assignment.
- `customer/`: Service discovery, booking flow, payment/invoicing, ratings.
- `worker/`: Job radar, acceptance, customer OTP handshake, welfare/earnings ledger.
- `cooperative/`: Primary society manager KYC queue, member roster, local fund balance.
- `federation/`: Apex federation analytics, cross-society balancing, AI demand allocation.
- `verification/`: Development-time diagnostics proving foundation integrity.
